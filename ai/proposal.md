# 需求

## 总需求

- 定时或周期的获取网络资料，主要是关于AI的 wiki、重要项目进展跟踪、产业新闻等。
	- 定时或周期可以是每天或者每周，或设置特殊时间点。
	- AI 的信息可以从 github 获取、某些wiki、重要AI厂商公开的技术文档（不是使用文档，而是关于实践、新技术等）。
	- 可以指定从重要项目（给出网址）中获取新闻。
	- 可以从一些新闻、消息、博客网站汇集。
- 根据原始信息，汇集成多个专题的信息。
	- 新闻：最新的消息（可以一周一次，或当前重大消息）
	- 技术汇总：新的技术和工具汇总。
- 其他要求
	- 可以考察原始资料的大小，本地只保存链接和简介。
	- 英文等外文翻译成中文。
	- 资料需要汇总，和比较一些趋势。

## 提案

- 制作一个工具，在后天运行，可以实现需求。
- 并且定时发送汇总到微信、公司内wiki等。
